# Matheus Oliveira — Portfólio

Portfólio pessoal com dois modos, alternados no canto superior direito:

- **Profissional** — layout limpo e objetivo.
- **Designer** — animações, cena 3D (Three.js) e circuito animado em Canvas 2D.

Feito com HTML, CSS e JavaScript puro.

## Adicionar projetos

Edite `js/dados-projetos.js`:

```js
var PROJETOS = [
  {
    titulo: 'Nome do projeto',
    descricao: 'Descrição curta',
    ano: '2026',
    tecnologias: ['JavaScript', 'MySQL'],
    link: 'https://...',
    imagem: 'img/projeto.jpg'
  }
];
```
